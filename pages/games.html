Add a game in three steps:
1. Create a folder such as games/my-game/ and put the playable page at games/my-game/index.html.
2. Add the custom icon to that folder, for example games/my-game/icon.png.
3. Copy an entry in js/games-data.js, set folder: "../games/my-game" and icon: "../games/my-game/icon.png", then edit the title, genre, description, and colours. The card, icon, genre filter, and Play button update automatically.
